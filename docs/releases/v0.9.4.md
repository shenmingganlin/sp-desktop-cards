# SP 桌面卡片 0.9.4

- 修复远程桌面切换分辨率、显示缩放变化时卡片尺寸异常的问题。卡片按应用保存的宽高恢复，移出屏幕的卡片会回到可见区域。折叠卡片仍保留展开后的高度。
- 修复嵌入桌面时卡片偶尔出现在 Windows 任务栏的问题。切换模式、重新显示和快速新建时，卡片保持隐藏任务栏按钮，仍可输入文字。系统托盘入口照常使用。

## 下载与升级

- `sp-desktop-cards-0.9.4-setup.exe`：Windows x64 安装版，可选安装目录。
- `sp-desktop-cards-0.9.4-win-x64.zip`：免安装版，完整解压后运行 `SP-Desktop-Cards.exe`。

启动新版前，请先从系统托盘退出正在运行的旧版。若旧版已保存了错误的卡片尺寸，可用「重新排列」恢复默认布局。安装版沿用原有用户数据位置，程序未签名。

## 发布验证

- 584 项自动测试和正式 EXE 的 7 个启动场景通过。安装包与免安装 ZIP 的内容、更新清单及校验和均已核对。
- 在 Windows 125% 缩放下，用真实 Electron 窗口模拟显示变化，验证尺寸恢复和任务栏窗口样式。实际远程桌面重连仍待现场验证。
