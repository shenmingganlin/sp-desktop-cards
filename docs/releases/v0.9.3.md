# SP 桌面卡片 0.9.3

本版把看板、艾森豪威尔矩阵和「结束这一天」带到公开版本，并集中修复计时顺序、任务创建反馈、日期计算与窗口恢复问题。

## 看板与 SP 同步

- 新增看板卡片，可在三列看板与艾森豪威尔矩阵之间切换，通过每行的 ⇄ 菜单换列。
- 按 SP 20 默认看板的系统标签 ID 分类；系统标签改名不影响分类，普通同名标签不会被合并或当成系统标签。标签缺失时说明如何在 SP 中创建。
- 换列前重新读取当前任务、标签及必要的项目状态，同一任务按顺序提交，保留最新的其他标签；无变化时不写入。
- 矩阵只显示父任务，矩阵换列保留完成状态；积压区任务需要先在 SP 中移出积压区。
- SP 完成任务时会移除进行中系统标签，取消完成后默认回到待办。卡片和 SP 使用同一行为。
- 卡片标明「SP 默认规则」。SP 的自定义列、筛选和手动排序无法从公开 API 读取，不承诺同步这些配置。

## 操作与稳定性

- 开始和停止计时在卡片、番茄钟之间共用本机队列，避免较早的异步操作覆盖较新的选择；失败后不自动重发写入。
- 新建任务的响应丢失时显示「结果未确认」，保留草稿并阻止重复回车；用户核对未创建后可解锁重试。换列、批量顺延与归档也区分成功、明确失败和待核实结果。
- 渲染进程异常退出后自动重建卡片；坏列表保留最后一份有效快照，接口恢复后自动重试。
- 修复隐藏全部与单卡关闭交错后卡片无法重新显示、托盘可见状态滞后，以及旧拖动或缩放覆盖救援位置的问题。
- 修复跨日新建、非零日界与夏令时的日程定位，保留子任务独立安排的时间块，避免父子任务预估重复累计。
- 设置读取暂时失败时保护旧配置；修复令牌保存与输入草稿的异步竞争、更新下载取消和外部主题重读。
- 今日卡片提供「结束这一天」菜单：顺延今日未完成项或归档已完成顶层任务，并说明不能单独归档的子任务。

## 下载与升级

- `sp-desktop-cards-0.9.3-setup.exe`：Windows x64 安装版，可选择安装目录。
- `sp-desktop-cards-0.9.3-win-x64.zip`：免安装版，完整解压后运行 `SP-Desktop-Cards.exe`。
- 本地构建另保留完整 `win-unpacked` 目录，可直接运行其中的 EXE。

安装版继续使用原 AppId 和用户数据位置。程序未签名。需要 SP 桌面版 19.3 或更新并开启本地 REST API；本次默认看板契约按 SP 20.0.0 核对。
